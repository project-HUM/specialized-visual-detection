# REDNOSE3

This directory owns the original pirate-ship capture profile, 360-frame
benchmark, canonical annotations, proof media, evaluation output, and review
launcher. These artifacts were migrated from the repository root without
changing the benchmark split or reviewed annotation content; only canonical
image paths were rebased to `maps/rednose3/dataset/images/`.

Run `run.bat` for the existing proposal-review queue. All shared commands must
select this workspace explicitly with `--map rednose3` when reproducibility is
important. `artifact_hashes.json` covers the current map-scoped locations.
